공공 기관 데이터는 대부분 사람이 보기 위한 형식으로 만들어집니다.


원래 상태

PDF · 한글(.hwp) · 비정형 엑셀

→ 컴퓨터는 숫자가 어디 있는지, 어떤 항목인지 알 수 없습니다

누군가 변환했습니다

컴퓨터가 읽기 좋은 구조화된 형식으로

→ 대시보드, 검색, 비교가 비로소 가능해졌습니다


오늘 쓴 대시보드는 그 변환 작업 위에서 돌아가고 있습니다.

구조화란 무엇인가?


구조화 = 컴퓨터가 규칙을 파악할 수 있도록 정해진 형식으로 정리하는 것


구조화되지 않은 데이터

2026년 교육부 예산(안)

  디지털 교육 혁신 사업
  ─────────────────────
  전년도 대비 12% 증가
  총 120억원 편성

어느 값이 금액인지 컴퓨터는 모름

구조화된 데이터

사업명: "디지털 교육 혁신"
코드: "2460101"
금액: 12000000000
전년대비: 0.12

항목과 값이 명확히 구분됨


오늘 실습에 쓴 데이터는 이미 이 형식으로 준비되어 있었습니다.

구조화가 있어야 할 수 있는 것들


구조화 없이 구조화가 있으면
금액 합산 불가 자동 집계·차트
특정 사업 검색 어려움 코드로 즉시 검색
연도별 비교 불가 키로 연결해 비교
대시보드 구현 불가 오늘 한 것


이번 학습의 핵심: 다양한 형식의 공공 데이터를 구조화하고 활용하는 것

AI 에이전트란?


기존 도구 (검색·엑셀) AI 에이전트
입력 정확한 명령·수식 자연어 의도
처리 사람이 단계마다 지시 스스로 계획·실행
결과 사람이 해석·조합 목표에 맞는 산출물 직접 생성
수정 처음부터 다시 대화로 방향 조정


에이전트는 “어떻게”가 아니라 “무엇을” 전달하면 됩니다.

AI 에이전트의 3요소


① 지시

.claude/ 폴더의 규칙·스킬

“이 프로젝트에서 어떻게 행동할지”

② 도구

파일 읽기·쓰기·실행·검색

“할 수 있는 행동의 목록”

③ 판단

Claude LLM

“지시와 도구를 조합해 목표 달성”


세 가지가 갖춰져야 에이전트가 자율적으로 작동합니다.

Claude Cowork가 방금 한 일


폴더 열기
  └─ .claude/ 읽기                ← 지시·스킬 로드

"이 프로젝트가 뭐 하는 건지 요약해줘"
  └─ index.html 읽기              ← 도구: 파일 읽기
  └─ 구조화된 데이터 파일 읽기    ← 도구: 파일 읽기  ★구조화 덕분에 가능
  └─ 한국어로 요약 생성           ← LLM 판단

"Top 5 차트 만들어줘"
  └─ 데이터에서 금액 항목 파악    ← 도구: 파일 읽기  ★구조화 덕분에 파악 가능
  └─ 차트 코드 작성               ← LLM 판단
  └─ index.html 수정              ← 도구: 파일 쓰기

에이전트가 데이터를 “이해”할 수 있었던 것은 구조화되어 있었기 때문입니다.

실무의 현실 — 데이터는 항상 준비되어 있지 않다


상태 예시 작업
① 완전 구조화 오늘 쓴 대시보드 데이터 바로 분석·시각화
② 부분 구조화 사람이 자유롭게 입력한 엑셀 (수기 메모·병합 셀 혼재) 정제 필요
③ 비구조화 PDF 예산서·한글 공문·스캔 이미지 추출·구조화 필요


공공 기관 데이터는 대부분 ②~③ 에 해당합니다.


AI 에이전트를 실무에 활용하려면 비구조화 데이터를 다루는 능력이 핵심입니다.

Cowork 실행 환경 점검


강사가 배포한 scripts/ 폴더에서:


  1. Cowork Readiness Check.exe 더블클릭
  2. 문제가 있다고 나오면 cowork_setup.bat 더블클릭
  3. UAC 팝업이 뜨면 예 클릭
  4. 재시작 안내가 나오면 저장 중인 작업을 저장한 뒤 재시작


cowork_setup.bat 는 Windows 의 Virtual Machine Platform 기능을 켭니다. Claude Cowork 가 내부 가상머신을 실행하는 데 필요한 기능입니다.

uv 는 따로 설치하지 않습니다


일부 Python 실습은 uv 라는 도구를 사용합니다.


하지만 학습자가 쓰는 Claude Cowork VM 안에는 uv 가 이미 준비되어 있습니다.


따라서 오늘은 내 Windows 에 uv 를 따로 설치하지 않습니다.

문제가 생기면 → docs/guide/99-문제해결.md

Claude Cowork로 저장소 열기


GitHub Desktop으로 클론한 저장소 전체를 Cowork에서 엽니다.


  1. Claude Desktop 실행

  2. 왼쪽 사이드바에서 Cowork 선택

  3. “Open workspace” 클릭

  4. GitHub Desktop이 클론한 폴더 선택

    예) C:\Users\나\Documents\GitHub\tutorials

  5. 채팅창에 입력:

    README.md 를 읽고, 이 저장소에서 W2-W4에 무엇을 하는지
3줄로 요약해줘.


이후 주차에는 저장소 전체가 아니라 그 주차에 사용할 하위 폴더 를 직접 여는 경우가 많습니다. 자세한 기준은 docs/guide/00-환경설치.md 를 봅니다.
