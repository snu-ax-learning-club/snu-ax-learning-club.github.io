코치가 준비한 것


학습자별 프로젝트 폴더가 저장소에 미리 만들어져 있습니다.


projects/
├── project-perfdata/
├── project-budget-nlq/
└── project-utility-billing/


각 폴더에는 README.md + attachments/ 만 들어 있습니다. 본인 폴더 위치는 코치가 1:1 로 안내드립니다.

일부러 최소 상태로 시작합니다. 데이터 구조 설계나 CLAUDE.md 같은 무거운 결정은 W4 이후로 미루고, 오늘은 도메인 자료를 그대로 펼쳐 봅니다.

Step 1 — 최신 폴더 받아오기


GitHub Desktop 에서:


  1. Current repository 가 tutorials 인지 확인
  2. Current branch 가 main 인지 확인
  3. 상단 Fetch origin → Pull origin 클릭


폴더 매핑이 W2 이후 영문화되었으므로 반드시 한 번 pull 해 주세요. 자세한 절차 → docs/guide/01-git-협업.md

Step 2 — 본인 폴더만 Cowork 에서 열기


저장소 전체가 아니라 본인 프로젝트 폴더 하나만 엽니다.


  1. Claude Desktop 실행 → 사이드바에서 Cowork 선택

  2. “Open workspace” 클릭

  3. 저장소 안의 본인 폴더 선택:

    예) C:\Users\나\Documents\GitHub\tutorials\projects\project-X


Cowork 는 열린 폴더만 봅니다. 본인 폴더만 열면 다른 자료에 휘둘리지 않습니다.

Step 3 — 처음 무엇을 물어볼까

채팅창에 아래 3개 프롬프트를 순서대로 보내 보세요. Claude 가 폴더 안 자료를 직접 읽고 다음 단계를 제안합니다.


1) 폴더 파악

README.md 를 먼저 읽고, 이 프로젝트가 어떤 일을 하려는 건지
3줄로 요약해줘. attachments/ 의 파일 목록과 각 파일이 무엇인지도
같이 알려줘.

Step 3 — 처음 무엇을 물어볼까 (계속)

2) 시작할 만한 작업 후보 받기

attachments/ 자료를 훑어 보고, 내가 이번 주에 시작할 수 있는
작은 작업 3가지를 제안해줘. 각 후보가 어떤 결과물을 낳는지,
얼마나 걸릴지도 짧게 알려줘.


3) 하나 골라서 첫 단계만 같이 하기

방금 제안한 후보 중 [N번] 을 골랐어. 우선 첫 단계만 같이 해 보자.
한 번에 하나씩 진행하고, 다음 단계로 넘어가기 전에 나한테 확인 받아줘.

길잡이 → docs/guide/02-내-프로젝트-시작하기.md

오늘의 핵심 — 가능성과 한계 체감


데이터가 아직 구조화되어 있지 않습니다 — 그래도 작은 자료에서는 Claude 가 꽤 잘 도와줄 수 있습니다.


잘 되는 일 (예상)

  • 자료 요약·목차 만들기
  • 시트 헤더 한눈에 정리
  • 작은 작업 후보 제안
  • 비정형 텍스트에서 핵심 추출

그래서 놓치기 쉬운 것

  • 다음 달에도 같은 결과가 나올까?
  • 다른 사람이 이어받아도 통할까?
  • 맞았는지 확인할 기준이 있나?
  • 다른 모델·도구에서도 재현될까?


“잘 됐다” 는 경험도 중요합니다. 다만 그 결과를 다시 쓸 수 있는 업무 자산 으로 남기려면 무엇이 더 필요한지 메모해 둡니다.

막혔을 때


  • 에러 메시지: 그대로 복사해서 Claude 에게 붙여넣기
  • 방금 한 변경 되돌리기: Cowork 에서 ESC 두 번
  • 그래도 막히면: 코치에게 손짓 / Notion 질문


자세한 가이드 → docs/guide/99-문제해결.md
