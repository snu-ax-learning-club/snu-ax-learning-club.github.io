질문에서 작업 흐름으로


질문형 AI 는 무엇을 물어볼지 정리하는 데 도움이 됩니다.


하지만 업무 산출물이 되려면 답변만으로는 부족합니다.


원본 데이터, 전처리 과정, 검증 기준이 함께 남아야 합니다.


그래서 오늘은 질문을 넘어, 반복 가능한 작업 흐름(workflow)을 만듭니다.

1. 작업 흐름 쪼개기

그대로 자동화하기 어려운 이유


6주차 워크플로우는 사람에게는 자연스럽지만, 에이전트에게는 여러 일이 한 덩어리로 섞여 있습니다.


  • 조건 선택과 파일 다운로드
  • 피벗 테이블 변환
  • 집행률 계산식 추가
  • 결과 해석


그래서 자동화하려면 반복 가능한 일 과 사람이 판단할 일 을 나눠야 합니다.

데이터 형태도 바꿉니다


6주차에는 엑셀 파일을 바로 피벗 테이블로 만들었습니다.


7주차에는 중간에 tidy CSV 를 둡니다.


열린재정 데이터
  -> 원본 묶음(raw)
  -> 전처리된 분석용 CSV(processed tidy CSV)
  -> 분석 산출물(derived)
  -> 엑셀 피벗 / 보고서


전처리된 분석용 CSV(processed tidy CSV)는 사람이 분석을 시작하는 기준 파일입니다.

보고서처럼 꾸민 표가 아니라, 피벗·필터·차트·코드가 다시 읽기 쉬운 표입니다.

Tidy data 란 무엇인가


Tidy data, 즉 분석하기 좋게 전처리된 데이터는 사람이 보기 좋은 보고서 표가 아니라, 분석과 자동화에 다시 쓰기 좋은 표입니다.


기본 생각은 단순합니다.


한 행 = 하나의 관측값
한 열 = 하나의 변수
한 셀 = 하나의 값


그래서 피벗 테이블, 필터, 집계, 차트로 이어가기 쉽습니다.

2. 준비한 4가지 스킬

4가지 스킬: 안내와 조율


오늘은 스킬 이름을 외우는 시간이 아닙니다.


각 스킬이 작업 흐름의 어느 부분을 맡는지만 알면 됩니다.


사용자 안내

open-fiscal-guide


무엇을 하려는지 정리하고, 필요한 다음 단계를 안내합니다.

전체 흐름 조율

open-fiscal-pipeline


수집, 전처리, 분석 설계 중 어느 단계가 필요한지 판단합니다.

4가지 스킬: 수집과 변환


반복 가능한 데이터 준비는 두 스킬이 맡습니다.


열린재정 자료 수집

open-fiscal-settlement-fetcher


열린재정 데이터를 가져오고 원본 묶음(raw)을 남깁니다.

tidy CSV 변환

open-fiscal-settlement-processor


원본(raw) 데이터를 엑셀에서 열 수 있는 tidy CSV 로 바꿉니다.

스킬이 해주는 범위


오늘 스킬로 할 수 있는 일은 여기까지입니다.


  • 열린재정 웹사이트/API 에서 필요한 데이터를 가져온다
  • 원본에 가까운 raw 데이터를 남긴다
  • 엑셀에서 열 수 있는 tidy CSV 파일로 변환한다
  • 수집 조건, 행 수, 합계 같은 검증 정보를 남긴다

전처리 데이터 이후


전처리된 분석용 CSV(processed tidy CSV)는 분석의 끝이 아니라 시작점입니다.


단계 할 일
1. 분석 피벗, 차트, 요약표로 질문을 탐색
2. 결과물 결정 보고서·대시보드·반복 분석표 중 산출물 선택
3. 작업 흐름 정리 반복할 절차와 검증 기준 확정
4. 스킬 전환 확정된 작업 흐름을 에이전트 스킬로 만들기

  • API key 값은 슬라이드나 채팅에 남기지 않습니다.
  • API key 값은 GitHub 에 커밋하지 않습니다.

예시 프롬프트


현재 프로젝트는 korea-fiscal-skills 저장소입니다.

열린재정 세출/지출 결산현황 데이터 중 2024년 교육부 자료만 수집하고,
엑셀에서 피벗 테이블로 분석할 수 있도록 tidy CSV 파일로 변환해줘.

API 호출을 줄이기 위해 2024년, 소관=교육부 범위로만 실행해줘.

작업 후에는 생성된 폴더 위치, CSV 파일명, 행 수,
그리고 사람이 엑셀에서 확인해야 할 항목을 정리해줘.

실행 후 확인할 것


에이전트가 파일을 만들었다고 끝이 아닙니다.


확인 항목 볼 것
폴더 raw 와 processed 가 생성됐는가
CSV 엑셀에서 한글과 열 이름이 잘 열리는가
범위 2024년 교육부 자료만 들어 있는가
행 수 이 범위의 수집 행 수와 변환 행 수가 설명되는가
금액 주요 금액 열이 숫자로 읽히는가

피벗 테이블로 분석표 만들기


전처리된 분석용 CSV(processed tidy CSV)를 바로 보고 끝내지 않습니다.


피벗 테이블로 질문별 요약표를 만들면, 그 요약표가 첫 번째 derived 데이터 가 됩니다.


분석 질문 피벗 테이블 구성
회계별 지출 규모는? 행: 회계명 / 값: 지출순액 합계
분야별 집행률 차이는? 행: 분야명 / 값: 지출계획현액 합계, 지출순액 합계

피벗 테이블 예시 더 보기


같은 CSV 에서 다른 질문도 이어서 만들 수 있습니다.


분석 질문 피벗 테이블 구성
부문별 지출 비중은? 행: 부문명 / 값: 지출순액 합계
집행률이 낮은 항목은? 행: 분야명 또는 사업명 / 값: 집행률

피벗 분석 프롬프트 예시


전처리된 분석용 CSV(processed tidy CSV)를 기준으로 피벗 테이블 구성을 먼저 제안받을 수 있습니다.


이 CSV 로 교육부 회계별 지출 규모를 보려면
엑셀 피벗 테이블에서 행, 열, 값에 무엇을 넣어야 하는지 알려줘.
분야별 집행률을 비교하고 싶어.
필요한 값 필드와 계산 필드를 어떻게 만들지 설명해줘.
집행률이 낮은 항목을 찾기 위한 피벗 테이블 구성을 제안해줘.
0 분모 처리와 정렬 기준도 함께 알려줘.

집행률 계산


피벗 테이블에서 합계를 만든 뒤, 오늘은 아래 계산식으로 집행률을 봅니다.


집행률 = 지출순액 / 지출계획현액


확인할 점:

  • 지출계획현액이 0인 행은 어떻게 처리할 것인가
  • 금액 단위가 연도별로 같은가
  • 평균을 낼 때 단순 평균과 금액 가중 평균 중 무엇이 맞는가
